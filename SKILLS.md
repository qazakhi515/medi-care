# Medi-care Backend Skills

Use these Codex skills for repeatable Medi-care backend workflows.

| Skill                   | Purpose                                                                                                                 |
| ----------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| `backend-migration`     | Continue the Nestar property backend to Medi-care backend modification while preserving the current NestJS architecture |
| `hospital-logic`        | Review hospital GraphQL, DTO, schema, enum, filter and naming consistency.                                              |
| `doctor-logic`          | Review doctor profile GraphQL, DTO, schema, enum, ownership and member reference consistency                            |
| `appointment-logic`     | Review patient appointment booking flow, references, statuses and double-booking rules.                                 |
| `payment-logic`         | Review appointment payment flow, statuses, payment methods and one-payment-per-appointment consistency.                 |
| `patient-profile-logic` | Review patient profile schema, DTO, enum and member reference consistency.                                              |
| `er-model-validation`   | Check Medi-care ER references, field types, enum values and old-domain terminology leaks.                               |

Each skill lives at skills/<skill-name>/SKILL.md.
